# obsidian-vault

**por** | [eng](README-en.md)

## Como usar este cofre

### 1. Instale o Obsidian

Baixe em [obsidian.md](https://obsidian.md/download) e instale.

### 2. Baixe o cofre

1. Acesse a página do repositório no **[GitHub](https://github.com/saayajin/obsidian-vault)**
2. Clique no botão verde **Code**.
3. Clique em **Download ZIP**.

### 3. Extraia o arquivo

1. Abra a pasta de downloads e localize o arquivo `.zip`.
2. Extraia a pasta 'Vault' e mova para um lugar fácil de achar, como **Documentos**.

### 4. Abra no Obsidian

1. Abra o Obsidian.
2. Clique em **Abrir pasta como cofre**.
3. Selecione a pasta que você extraiu e confirme.
4. Se aparecer um aviso sobre plugins da comunidade, clique em **Confiar no autor e ativar plugins**. Sem isso, os plugins não funcionam.
5. Abra as configurações do plugin **Templater** e habilite a opção **Enable startup templates**
6. Reinicie o aplicativo para que o script habilite os demais plugins.

### 5. Pronto

O cofre abrirá com o tema, os snippets e os plugins já configurados.

### Problemas comuns

| Problema | Solução |
|---|---|
| O Obsidian mostra um cofre vazio | Você escolheu a pasta errada. Selecione a que contém diretamente as notas e as pastas do cofre (às vezes há uma pasta dentro da outra após extrair) |
| Os plugins não aparecem | Vá em **Configurações > Plugins da comunidade** e ative a opção para permitir plugins |
| A aparência está diferente | Vá em **Configurações > Aparência** e confira se o tema e os snippets estão ativados |
