# obsidian-vault

[por](README.md) | **eng**

## How to use this vault

### 1. Install Obsidian

Download it from [obsidian.md](https://obsidian.md/download) and install it.

### 2. Download the vault

1. Go to the repository page on **[GitHub](https://github.com/saayajin/obsidian-vault)**
2. Click the green **Code** button.
3. Click **Download ZIP**.

### 3. Extract the file

1. Open your downloads folder and find the `.zip` file.
2. Extract the 'Vault' folder and move it somewhere easy to find, like **Documents**.

### 4. Open it in Obsidian

1. Open Obsidian.
2. Click **Open folder as vault**.
3. Select the folder you extracted and confirm.
4. If a warning about community plugins appears, click **Trust author and enable plugins**. Without this, the plugins won't work.
5. Open the **Templater** plugin settings and switch **Enable startup templates** option to on.
6. Restart the application so that the script can enable the remaining plugins.

### 5. Done

The vault will open with the theme, snippets, and plugins already set up.

### Common problems

| Problem | Solution |
|---|---|
| Obsidian shows an empty vault | You picked the wrong folder. Select the one that directly contains the notes and vault folders (sometimes there is a folder inside another one after extracting) |
| Plugins don't show up | Go to **Settings > Community plugins** and turn on community plugins |
| The look is different | Go to **Settings > Appearance** and check that the theme and snippets are enabled |
